# Tanzanian Water Pump Maintenance

Predictive maintenance and intervention prioritization for water pumps in Tanzania.

## Objective

Develop a data-driven approach to identify pumps that are likely to be non-functional or require repairs, and translate these predictions into a practical maintenance prioritization strategy.

## Data

This project uses the DrivenData *Pump it Up: Data Mining the Water Table* dataset.

Download the competition data from:
https://www.drivendata.org/competitions/7/pump-it-up-data-mining-the-water-table/

Place the downloaded CSV files in `data/raw/`. The original data files are excluded from this repository in accordance with the dataset's redistribution terms.
